# Blockers found running live on Nov 6 2026 (25 Equity tickers, Options on 9)

Purpose (user, Nov 6): run the system far enough to find every blocker, then evaluate which checks the system really
needs and refactor the rest. Each row is a check that stopped or degraded the live run. "First view" is Claude's
initial assessment for the user's review, not a decision. Root causes for onboarding are in
`TICKER_ONBOARDING_GUARDS.md`; full evidence is in `docs/agent-context/advanced-realtime-integration-gaps.md`.

## Pattern behind most of them

1. **Whole-run failure for a local problem.** One ticker, one consumer or one product fails, and the check raises for
   the whole window, plan or service. Nothing has a per-item degrade path.
2. **Terminal by design, no in-hours recovery.** Blocked plans and quarantined journals are immutable for the session.
   The only way back was a manual database override.
3. **Fixed universes in code.** SPY/QQQ and the original 9 tickers are literals in runtime paths, so growing the
   universe breaks code that was never meant to be a guard.
4. **Crash and restart instead of waiting.** Services exit on a refused precondition, so Docker restarts them into
   a crash loop, and the real error is only found by reading logs.
